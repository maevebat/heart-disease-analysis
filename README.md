# Heart Disease Data Analysis
Exploratory data analysis of a synthetic clinical dataset to investigate relationships between patient characteristics and heart disease.
The project analyzes numerical and categorical variables using visualization and statistical testing to identify patterns associated with disease status.

## Research Questions
- Is age associated with heart disease?
- Do clinical variables (cholesterol, blood pressure) differ between groups?
- Are lifestyle factors such as smoking or diabetes related to heart disease?

## Methods
- Exploratory Data Analysis (EDA)
- Data visualization
- Mann–Whitney U test
- Chi-square test

## Technologies
Python, pandas, matplotlib, seaborn, scipy

## Dataset

Synthetic heart disease dataset from Kaggle:  
https://www.kaggle.com/datasets/pratyushpuri/heart-disease-dataset-3k-rows-python-code-2025
